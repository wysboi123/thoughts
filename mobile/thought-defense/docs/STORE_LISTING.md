## Full description

Thought Defense is a calm tower-defense game set in a soft mindscape.

Negative thoughts — Doubt, Worry, Self-Critic — walk the path. You plant positive thoughts as towers: Affirmation, Gratitude, and Humor. Protect your Peace Core. Upgrade when you are ready. Take a breath between waves.

This is a metaphor game for quiet focus. It is not therapy, diagnosis, or medical advice.

Optional Clarity Pass and cosmetic packs support the project without locking the core calm loop. Restore purchases anytime in Settings.
