# Couch Galaxy

Apartment roof hangout that opens into a low-poly night sky. Sit on the couch, step through the skylight portal, float among soft star pads.

## Play

```bash
cd games/couch-galaxy
rojo build -o CouchGalaxy.rbxl
rojo serve
```

## Loop (v0)

1. Spawn in the apartment
2. Sit on the couch (optional)
3. Touch the **skylight portal** on the roof → teleport into the galaxy loft
4. Collect star motes / bounce on cloud pads
5. Touch the return beacon to come home
