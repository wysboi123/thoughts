# Couch Galaxy

Apartment roof hangout that opens into a low-poly night sky.

## Play

```bash
cd games/couch-galaxy
rojo build -o CouchGalaxy.rbxl
rojo serve
```

## Loop (v0.1)

1. Spawn in the apartment — dual couch seats (sit sync shows who’s chilling)
2. Climb stairs to the roof (railings, planters, string lights)
3. Touch the **skylight portal** → galaxy loft
4. Collect star motes along constellation beams / bounce on cloud pads
5. Touch the warm return beacon to come home
