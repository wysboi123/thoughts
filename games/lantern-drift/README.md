# Lantern Drift

Fog lake. Soft raft. Floating lanterns. Sit and drift — no race, no fail.

## Play

```bash
cd games/lantern-drift
rojo build -o LanternDrift.rbxl
rojo serve
```

## Loop (v0)

- Spawn on the dock
- Step onto the raft (it gently drifts)
- Collect floating lanterns
- Sit on the raft seat
- Soft goals optional
