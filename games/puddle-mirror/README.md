# Puddle Mirror

> **Parked for later (2026-09-29).** Files kept — do not erase. Active overnight focus is Haze / Couch / Bus / Porch.

Reflective floor world. Step on puddles to unlock secret nooks — then a deeper mirror room.

## Play

```bash
cd games/puddle-mirror
rojo build -o PuddleMirror.rbxl
rojo serve
```

## Loop (v0.2)

- Walk the mirror plaza
- Step glowing puddles → ripple FX + unlock nooks
- Collect dew drops (with soft trails)
- Unlock all three nooks → **Deep Mirror** chamber
- Soft session goals (top-right) — optional
