# Star Porch

A wooden night porch under a soft starfield. Sit, collect fireflies, stay quiet.

## Play

```bash
cd games/star-porch
rojo build -o StarPorch.rbxl
rojo serve
```

## Loop (v3.8)

1. Spawn on the porch under string lights + moon
2. Walk the yard path / step gap in the rail
3. Sit a rocking chair or the porch swing (side table + warm mug)
4. Touch drifting fireflies — the **jar fills** as the session collects
5. Soft company nearby → jar/lights/fire warmer; fireflies drift toward jar
6. Visual wind chime sways (audio blocked on Perplexity)

**USP:** Jar that fills — fireflies drift back; the jar remembers.
