# Star Porch

A wooden night porch under a soft starfield. Sit, collect fireflies, stay quiet.

## Play

```bash
cd games/star-porch
rojo build -o StarPorch.rbxl
rojo serve
```

## Loop (v0.4)

1. Spawn on the porch under string lights + moon
2. Walk the yard path / step gap in the rail
3. Sit a rocking chair or the porch swing (side table + warm mug)
4. Touch drifting fireflies (soft collect, they return)
5. Visual wind chime sways (audio blocked on Perplexity)
6. Soft welcome + proximity glow + SoftSit on join
